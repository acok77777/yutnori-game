
# 🪵 신나는 윷놀이

윷을 던져 도·개·걸·윷·모·백도 결과를 확인하는
한국 전통 윷놀이 미니 게임입니다.

## 🎮 게임 실행

https://acok77777.github.io/yutnori-game/

## ✨ 주요 기능

- 윷 던지기 애니메이션
- 윷 4개의 앞면과 뒷면 표시
- 도: 뒷면 1개, 앞으로 1칸
- 개: 뒷면 2개, 앞으로 2칸
- 걸: 뒷면 3개, 앞으로 3칸
- 윷: 뒷면 4개, 앞으로 4칸
- 모: 앞면 4개, 앞으로 5칸
- 백도: 별 표시 윷만 뒷면이면 뒤로 1칸
- 윷 또는 모가 나오면 추가 던지기 안내
- PC 및 모바일 반응형 화면
- 링크 공유용 미리보기 이미지
- 브라우저 아이콘 및 모바일 홈 화면 아이콘 설정

## 🖼️ 미리보기 이미지

`yut-preview.png` 파일을 링크 공유용 이미지로 사용합니다.

Open Graph 메타 태그를 통해 제목, 설명 및 이미지를
카카오톡 등 미리보기를 지원하는 서비스에 제공합니다.

## 📱 홈 화면에 추가

### Android

1. Chrome에서 게임 주소를 엽니다.
2. 브라우저 메뉴를 누릅니다.
3. '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.
4. 화면의 안내에 따라 추가합니다.

### iPhone

1. Safari에서 게임 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. '홈 화면에 추가'를 선택합니다.
4. 추가를 누릅니다.

참고: 홈 화면 아이콘이 미리보기 이미지와 동일하게
표시되는지는 기기와 브라우저에 따라 다를 수 있습니다.

## 🚀 GitHub Pages 배포 방법

1. GitHub 저장소에서 파일을 수정하거나 업로드합니다.
2. Settings → Pages로 이동합니다.
3. Deploy from a branch를 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 설정합니다.
5. 저장하고 배포가 완료될 때까지 기다립니다.

## 🔄 링크 미리보기가 표시되지 않을 때

- GitHub Pages 배포가 완료되었는지 확인합니다.
- 아래 이미지 주소가 브라우저에서 열리는지 확인합니다.

  https://acok77777.github.io/yutnori-game/yut-preview.png

- 메신저에서 이전 미리보기를 캐시했을 수 있으므로
  잠시 기다린 후 다시 공유해 봅니다.
