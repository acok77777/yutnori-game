# 🎲 신나는 윷놀이

도·개·걸·윷·모 중 하나가 랜덤으로 나오는
한국 전통 윷놀이 미니 게임입니다.

## 📁 파일 구성

yutnori-game/
├── index.html
├── style.css
├── script.js
└── README.md

## ✨ 주요 기능

- 윷 던지기 애니메이션
- 도·개·걸·윷·모 랜덤 결과
- 같은 결과가 연속으로 나올 수 있음
- 윷·모가 나오면 추가 던지기 안내
- 최근 20회 결과 기록
- 효과음 켜기 및 끄기
- 게임 기록 초기화
- 모바일 및 PC 반응형 디자인
- 별도의 이미지 파일 없이 실행

## 🚀 GitHub Pages 배포 방법

1. GitHub에서 `yutnori-game` 저장소를 만듭니다.
2. 네 파일을 저장소 최상위에 업로드합니다.
3. Settings → Pages로 이동합니다.
4. Deploy from a branch를 선택합니다.
5. Branch는 `main`을 선택합니다.
6. 폴더는 `/(root)`를 선택합니다.
7. Save를 누릅니다.
8. 배포가 완료되면 아래 주소로 접속합니다.

https://acok77777.github.io/yutnori-game/

## 🎮 게임 방법

1. 윷 던지기 버튼을 누릅니다.
2. 윷이 굴러가는 애니메이션을 확인합니다.
3. 도·개·걸·윷·모 결과를 확인합니다.
4. 윷 또는 모가 나오면 추가로 던질 수 있습니다.
5. 처음부터 버튼을 누르면 기록이 초기화됩니다.

## 📝 참고

현재 버전은 놀이용 랜덤 결과를 사용합니다.
실제 윷 네 개의 앞뒤 면 조합에 따른
전통적인 결과 판정은 구현하지 않았습니다.
